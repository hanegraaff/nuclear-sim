# UI

React mounts the full-viewport map and displays loading or imagery-failure feedback. The upper-left `DevicePanel` has keyboard-accessible Scenario and Device tabs, native grouped selectors, custom input, and Reset; each dispatches a semantic action to the pure application reducer. It uses packaged Geist fonts, the prototype's compact dark shape, and live selection and launch status. Multi-launch, night, and hide controls arrive in later plans.

An invalid custom-yield draft is preserved across tabs, but its error appears only alongside the editable Device input. The Scenario tab remains usable and explains that a scenario can prepare a device.

`MapViewport` creates a rendering-owned controller on mount and disposes it on unmount. This cleanup also supports React Strict Mode's development remount. It forwards the application's camera request to the controller and receives readiness and camera snapshots through callbacks, without holding a MapLibre map. The map remains interactive when imagery fails, and the retry button refreshes satellite tiles while preserving the map style and any future effect layers.

For Plans 04–05, `App` creates an application-owned `SimulatorStore` with the browser's monotonic clock and frame scheduler, then subscribes to its snapshots. The device panel is memoized and does not repaint on every animation frame. `MapViewport` forwards geographic launch routes, an injected launch angle, and immutable launch frames across the rendering boundary. The status announces inbound, expansion, and completion; an invalid custom yield prevents launch. A second click replaces the current strike, and Reset clears it without changing camera or device. The short scientific qualification stays visible along the lower edge.

Plan 06 adds `BlastInspectionOverlay`, which renders four transparent focusable marker hit targets from renderer-supplied CSS-pixel positions only after expansion completes. The renderer paints their visible rings alongside the ruler in one canvas frame. Hover, focus, click, and Escape dispatch semantic inspection actions to the application store. One tooltip shows the prototype descriptions plus modeled span and spherical area; its position is clamped inside the viewport. The marker layer does not cover the map except at its buttons, and marker activation cannot launch another strike.
