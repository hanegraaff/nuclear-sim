# Application state

This package owns selection, launch groups, phases, inspection state, and clock progression. It imports catalog and pure domain functions, but no React component, map instance, Canvas, or WebGL object. UI components dispatch semantic actions and render immutable snapshots; drawing code consumes derived launch frames.

`deviceSelection.ts` validates fixed catalog IDs and custom yields. The default is Fat Man. Custom input accepts finite 0.000000001–1,000,000,000 Mt and consistent three-digit separators; an invalid draft remains visible when the user returns to the Device tab and cannot launch. `scenarioSelection.ts` composes that selection with the Scenario tab. Selecting one of 20 scenarios prepares a device and issues a geographic camera request without detonating. Changing device clears the selected scenario.

`launch.ts` defines `LaunchGroup` as one map click. `reduceSimulator` freezes a click's selected device, geographic route, yield, modeled radii, and monotonic start time. A normal group has one delivery. A MIRV group creates the catalog's three or ten deterministic geographic targets and stores one shared carrier route and separation time; each delivery keeps its own per-warhead yield, arrival time, and radii. Single mode replaces the prior group, including an active flight. Multi mode appends groups, and turning it off retains the latest whole group. `launchFramesForState` derives every delivery's age, so one missile can approach while older fields expand or remain settled. Aggregate phase reports active detonation before inbound flight; Reset clears groups and inspection without changing device, mode, or map camera.

`SimulatorStore.ts` owns the injected monotonic clock, one cancellable animation-frame request, subscriber notification, and launch validation. It ignores stale callbacks after replacement or Reset and stops scheduling when no group is active. A multi session keeps one general carrier-entry bearing across clicks; each target and route remains separate. Focused tests use fake time and deterministic angles, so wall-clock scheduling and random entry directions cannot affect results.

The reducer stores hovered, focused, pinned, and derived active inspection IDs rather than popup pixels. Hover takes precedence over focus, then a pinned marker; Escape clears inspection. `cloudPresentationForState` reads the latest group and its first ignited warhead to derive phase, modeled height, nuclear or conventional wording, and per-warhead labels from the pure cloud model. Before ignition it shows standby; after Reset the selected device again supplies the standby scale. The renderer receives this presentation object and does not calculate cloud physics or own the clock.
