# Inspection overlays

`blastInspection.ts` receives immutable blast radii in kilometers, an impact `GeoPoint`, and a small camera projection interface. `selectBlastRulerBearing` chooses a viewport-fitting direction once per strike. `buildBlastInspection` uses that fixed bearing and the current camera to return ring, ruler, and marker geometry in CSS pixels while retaining physical zone spans and areas. `drawBlastInspection` paints the ruler and visible marker rings together so they cannot visually separate during zoom. The module owns prototype marker colors, not yield formulas, time, or MapLibre state. Its projection interface is faked in integration tests. Geometry is rebuilt when the camera moves or the viewport resizes; a missing or unprojectable ruler suppresses interactive markers rather than placing them at invalid coordinates.

`mapDistanceScale.ts` supplies a lower-left multi-mode distance bar. Its public `mapDistanceScale` uses center latitude and MapLibre zoom to choose a readable 1/2/5 kilometer step, then bounds the bar width between 54 and 158 CSS pixels. It is a camera-center ground-scale reference; a pitched map has different local scale across the viewport. The four effect markers belong to the UI legend, not geographic points, so they remain attached to their gradient track during pan and zoom. The tooltip's quantitative zone span comes from the latest strike rather than a fictitious combined device.

`falloutInspection.ts` builds a 43-point curved H+24 ruler from the modeled nuclear field. Four marker positions sit at the midpoints of inner-to-outer physical downwind spans; their yellow, orange, pink, and purple rings identify Lethal Dose, Critical Dose, Acute Sickness, and Contaminated bands. These names and Gy ranges retain the prototype's illustrative screening language. The field painter draws the ruler and markers in the same camera frame, and React receives the same CSS-pixel geometry for transparent hit targets and bounded popups. Unprojectable or off-viewport markers are omitted rather than parked at invalid coordinates. Single-mode inspection describes the first retained nuclear footprint even when a MIRV contributes several fields. Multi-mode Fallout uses the newest nuclear delivery's application-derived spans and approximate km² areas in a fixed legend, not a combined dose or a geographic ruler.

`audibleInspection.ts` builds a 43-point geodesic range ruler with four marker midpoints from the model's Faint, Loud, Painful, and Deafening kilometer spans. The renderer paints the dashed line and marker rings on a transparent inspection canvas without adding hard color boundaries to the underlying green field. It returns current CSS-pixel positions to React for focusable hit targets; invalid or off-viewport markers do not become clickable. The endpoint label reports the latest retained delivery's modeled audible radius. Multi mode removes that geographic ruler and uses the fixed four-band legend plus camera-center distance bar. Its span and illustrative peak-dB copy describe the latest delivery, while the map shows bounded combined intensity from all retained fields.

`visibleInspection.ts` uses the same current camera to project a 43-point direct-fireball sightline ruler and midpoints of the Faint, Clear, Brilliant, and Blinding spans. It paints a dashed ruler and blue marker rings, then returns CSS-pixel anchors for React hit targets; off-viewport or invalid projections cannot become interactive. The endpoint label reports one delivery's modeled horizon. Multi mode uses the fixed blue legend and camera-center scale, with spans from the newest delivery and a bounded combined field from all retained impacts.
