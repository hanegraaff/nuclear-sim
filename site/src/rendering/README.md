# Rendering

Rendering adapters translate immutable model results into MapLibre camera coordinates and, in later plans, Canvas/WebGL effects. The model never depends on this area.

Plan 01 provides the MapLibre satellite style/factory, `MapCameraAdapter`, and `SatelliteMapController`. The camera adapter projects and unprojects geographic points through a small interface that tests can fake. The controller is the UI-facing map API: `createSatelliteMapController` mounts the map, callbacks publish readiness and camera position, `retryImagery` reloads only the satellite tiles, and `dispose` removes listeners and the map. MapLibre objects stay inside this area. Readiness waits for MapLibre's idle event so live tiles can fill the viewport. A successful satellite tile clears a transient imagery error and returns to loading until idle; errors from other sources do not claim the imagery is unavailable. Plan 02 uses `setPanelsVisible` and resize-aware padding to keep the camera's visual center clear of the left control panel. The raster style declares imagery attribution. The factory sets MapLibre's bundled worker URL before creating a map, as required by MapLibre's Vite integration.

Plan 03 adds `focusScenario`: it turns a supplied center and modeled horizon into the prototype's viewport-dependent zoom and a 650 ms camera ease. Scenario navigation reports imagery loading until the destination source reaches idle, including when uncached tiles are slow. `scenarioZoom` contains only projection and viewport framing; the yield-based horizon comes from the domain layer.

Plan 04 adds `animation/flightGeometry.ts` and `MissileCanvasRenderer.ts`. The controller converts a map click into a geographic route using the current camera, then sends it to the application. The route starts 14 CSS pixels inside a viewport edge at click time, but its start, control, and target are immediately stored in geographic degrees. Each frame projects those three points through the current camera before sampling the prototype's screen-space quadratic curve; the map adapter chooses the nearest world copy across the antimeridian. A transparent canvas draws the red pulse, smoke, and amber carrier without intercepting map controls. Each smoke segment endpoint uses its own younger age and seed. `setFlightFrame` takes an immutable launch and elapsed milliseconds; the renderer owns no timing or device state. The flight angle is injectable through the map callbacks and varies by launch in production while the first launch remains fixed for visual review.

Plan 05 adds `effects/BlastCanvasRenderer.ts` and `effects/blastFieldGeometry.ts` behind the same controller. The renderer receives one immutable launch and elapsed milliseconds. Its cached mask unprojects visible pixels through the current camera and measures great-circle distance in kilometers from the target. Each animation frame uses that distance grid to paint the expanding field with the prototype's exact white, orange, magenta, and purple anchors; the shock ring uses geographic destinations. Camera move and resize invalidate the grid, while replacement and Reset clear it. A white-gold corona adds optical brightness at ground zero without changing modeled radii. The missile reticle leaves at impact so it cannot cover the blast center. Ground-mesh refinements in pitched views are staged for Plan 07. Rendering owns no yield formula or clock. See [effects](effects/README.md) for the mask contract.

Plan 06 adds `overlays/blastInspection.ts`. Its public `buildBlastInspection` projects four geodesic rings, a dashed radial ruler, and zone midpoint markers through the current camera. `selectBlastRulerBearing` chooses a screen-fitting direction once per settled strike; subsequent camera changes preserve that bearing. `drawBlastInspection` paints the ruler and visible marker rings in the same canvas frame, while the controller returns projected positions for transparent keyboard and pointer targets in the UI. See [overlays](overlays/README.md) for its projection contract. Pitched-ground refinements remain in Plan 07.
