# Rendering and map

This package turns immutable geographic launch frames and model results into visible map effects. MapLibre owns the satellite camera and imagery; Canvas draws ground fields, missiles, smoke, the cloud instrument, and inspection artwork; a small MapLibre-aligned WebGL2 layer draws the raised fireballs. Neither the map controller nor a painter chooses device yields or advances the application clock.

`MapCameraAdapter` projects and unprojects geographic points and selects a nearby world copy across the antimeridian. `SatelliteMapController` is the narrow UI-facing map API. It creates the map, translates clicks into geographic flight routes, sends readiness/camera/inspection callbacks, focuses a scenario, accepts scene frames, retries failed imagery tiles, and disposes listeners and GPU resources. Imagery readiness waits for MapLibre idle after visible tiles load. Source-specific tile errors do not replace the map style or erase effects. The raster source keeps Esri attribution visible.

A click stores the carrier start, curved control, and target as geographic coordinates even though the starting point comes from the current viewport edge. Each frame projects them through the current camera before evaluating the visual curve. For a MIRV, one carrier is drawn until its shared separation clock; continuous branches then lead to the distinct geographic targets. The controller can fit an otherwise hidden MIRV spread on a narrow viewport, using a numeric clear-area measurement from the UI rather than reading UI markup. This camera ease does not alter targets or routes. [Animation rendering](animation/README.md) explains missile, smoke, flash, and fireball contracts.

[Effect rendering](effects/README.md) samples the map's visible geographic ground in kilometers. The single field caches distance and color samples; the combined compositor uses one shared ground grid and bounded chunks for overlapping groups. Pan, zoom, pitch, bearing, resize, replacement, and Reset invalidate the relevant projection caches. The optical white-gold center and 3D dome do not change the modeled damage radii. A failed WebGL context leaves the 2D flash and field usable.

[Inspection overlays](overlays/README.md) project geodesic zone rings, ruler, and markers through the same camera. Their visible rings and dashed line paint in a transparent canvas above the dome; UI-owned hit targets use the returned CSS-pixel positions. Multi mode removes the single ruler and rings and presents a camera-center distance scale with a fixed legend. Turning multi mode off keeps the latest whole group: every retained impact remains visible, with inspection attached to the latest delivery. The independent [cloud renderer](cloud/README.md) receives application-derived height and phase, never a map camera.

Tests use reversible fake projection, fake map events, fixed tiles, and deterministic clock frames. The visible result should stay attached to geographic ground as the camera moves; screen pixels are only a drawing output.
