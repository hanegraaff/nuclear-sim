# Device and scenario catalog

`devices.ts` is the typed source of truth for 52 fixed choices in four groups: the 47 prototype entries and five additional conventional weapons. IDs, names, displayed yields, and internal megaton yields remain stable. The conventional group is ordered by ascending TNT-equivalent yield; other groups retain prototype order. The added estimates use specified explosive fills and approximate peak-pressure equivalence, with assumptions in [model notes](../../docs/model.md). MIRV entries distinguish aggregate display yield from per-warhead yield; `perWarheadYieldMt` returns the latter for one impact. `getDeviceById` returns `undefined` for unknown IDs, and `isConventionalDevice` identifies deliveries that receive a conventional plume and no nuclear Fallout footprint.

Custom yield is an application input and is not counted among the 52 fixed devices. `scenarios.ts` contains the 20 prototype labels, categories, device mappings, and coordinates in degrees. `getScenarioById` returns an entry or `undefined`. Catalog tests protect their values and the approved conventional ordering.

`previewTypes.ts` defines display-only dossiers and scenario records. `deviceDossiers.ts` supplies exterior facts, confidence, per-field source URLs, qualified outlines, and notes for every fixed device; `scenarioPreviews.ts` pairs each scenario with static artwork and a researched event description. These modules are loaded with the desktop preview and do not feed physics calculations. Estimated facts are marked **(est)**, reported claims remain qualified, and unknown or inapplicable fields are explicit. One-off test apparatus, MIRV carriers, and hypothetical studies are identified so an illustration cannot imply a documented operational weapon. The custom preview states that no physical weapon is specified.

The [research ledger](../../docs/catalog-research.md) records sources, conversions, variant ambiguities, and limits. [Artwork notes](../../docs/preview-artwork.md) describe the generated illustrations and prompt set. Neither imagery nor event prose is a forecast or archival photograph.
